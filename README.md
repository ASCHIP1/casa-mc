# Casa MC · Aschip

Percurso interactivo por uma moradia de dois pisos desenhada pela Aschip, gabinete de arquitectura (Angola).

Site estático: `index.html` + `scrollcraft.js/css` (motor de scroll) + `maquete.js` (maquete 3D em three.js 0.160, licença MIT em `vendor/three/LICENSE`). Fonte Roboto (Google, licença aberta). Imagens e modelo: Aschip.
